## 📝 完整内容：5 个超实用车机设置

**来源：** 邓邓 dd-（2025-10-27，175 赞）

### 1. 近车自动解锁
- **功能：** 携带钥匙靠近车身，把手自动弹出，无需掏出钥匙
- **设置路径：** 设置 → 车辆控制 → 车锁 → 近车自动解锁（➕离车自动上锁）

### 2. 主驾座椅迎宾
- **功能：** 停车开门时座椅自动后退，方便下车；上车后自动恢复驾驶位置
- **设置路径：** 设置 → 车辆控制 → 更多 → 迎宾模式 → 主驾座椅迎宾

### 3. 头枕音响（驾享模式）
- **功能：** 导航声只通过主驾头枕发出，与车内音乐互不干扰
- **设置路径：** 设置 → 声音 → 头枕 → 头枕模式 → 驾享模式

### 4. 转向灯激活影像
- **功能：** 变道/转弯时激活两侧后视画面，弥补盲区视野
- **设置路径：** 设置 → 辅助驾驶 → 全景环视 → 转向灯激活影像
- **用户反馈：** 画面太小且居中，看不清

### 5. 车机导航和手机互联
- **功能：** 绑定高德账号，手机导航一键发送到车机
- **设置路径：** HUAWEI ADS → 设置 → 个人中心 → 导航模式 → 绑定高德账号
- **注意：** 可能需要开通高阶智驾

## ⚠️ 用户反馈问题

1. **转向灯影像太小** - 多位用户反映画面太小且居中，看不清
2. **没有前备箱** - 用户期待电动前备箱，后备箱下沉空间利用率低
3. **非华为手机互联限制** - 部分功能无法与鸿蒙座舱无缝衔接
4. **黑色车漆易划痕** - 销售推荐金色，但用户觉得黑色更好看
